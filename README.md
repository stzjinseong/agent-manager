# 클로드 키우기 (agent-manager)

내 PC 에서 돌리는 **여러 개의 Claude Code 세션을 한 화면에서 관리**하는 로컬 대시보드입니다.

터미널 창 3~4개를 오가며 "누가 뭘 하고 있지? 누가 승인을 기다리지?"를 확인하던 일을 브라우저 한 곳에서 합니다.
각 Claude 세션을 **워커**라고 부르고, 나는 매니저로서 일을 나눠 주고 · 진행을 지켜보고 · 승인 요청에 답합니다.

- **내 PC 전용** — `127.0.0.1` 에서만 열리고 외부로 나가는 통신이 없습니다. 팀 공유·원격 접속 기능은 없습니다.
- **기존 Claude Code 그대로** — 워커는 평소 쓰는 `claude` CLI 를 그대로 실행한 것이라 슬래시 명령·스킬·MCP·설정이 모두 같습니다.

---

## 이런 걸 할 수 있어요

| | |
|---|---|
| 🧭 **한눈에 보기** | 워커마다 카드 하나 — 작업 중 / 결정 필요 / 완료 / 백그라운드 대기 등 상태와 지금 하는 일, 컨텍스트 사용량 |
| 🔐 **승인 요청 모아 받기** | 권한 요청이 화면 위 결정함에 모입니다. 허용 / 거부 / 사유와 함께 거부를 버튼으로 |
| 📨 **업무 지시** | 작업 중이면 대기열에 쌓였다가 지금 일이 끝나면 자동으로 이어서 투입 |
| 📝 **나중에 할 작업** | 바로 보내지 않을 아이디어를 워커별로 적어 두었다가 ▶ 지시 한 번에 투입 |
| 🖥 **실제 터미널** | 카드를 누르면 그 워커의 Claude 터미널이 그대로 열립니다. 직접 입력해도 됩니다 |
| 📊 **세션 프로파일** | 턴별 토큰 · 캐시 · 추정 비용 · 소요 시간(모델/도구/승인 대기) · 도구 사용 · 서브에이전트 |
| 📈 **워커 비교** | 워커들의 누적 토큰 · 비용 · 캐시 적중률 · 컨텍스트 사용량을 나란히 |
| ♻️ **끊기지 않는 워커** | 대시보드 서버를 재시작해도 Claude 세션은 그대로 살아 있고 다시 붙습니다 |

## 준비물

- **Node.js 20 이상** (24 에서 확인)
- **Claude Code CLI** — 터미널에서 `claude` 가 실행되고 로그인까지 되어 있어야 합니다
- Windows 10/11 또는 macOS

## 설치

```bash
git clone https://github.com/stzjinseong/agent-manager.git
cd agent-manager
npm install
```

macOS 는 이어서 한 번 더:

```bash
npm run setup-mac
```

실행 파일 권한 설정, 창 없이 여는 `Launch.app` 생성, 터미널 명령 `agent-manager` 등록(`~/.zshrc`)을 해 줍니다.
`Launch.app` 을 처음 열 때 보안 경고가 뜨면 Finder 에서 **우클릭 → 열기**.

Claude Code 로 설치해도 됩니다. 클론한 폴더에서 `claude` 를 열고 `/setup --mac`(Windows 는 `/setup --windows`, 생략하면 OS 자동 판별).
준비물 확인 → `npm install` → OS별 설치까지 대신 돌리고 결과를 확인해 줍니다.

## 실행

프로젝트 폴더의 실행 파일을 더블클릭하세요. 서버가 뜨고 브라우저가 열립니다.

| | 창 없이 (보통 이걸로) | 콘솔 창과 함께 (문제 볼 때) |
|---|---|---|
| Windows | `Launch.vbs` | `Launch.bat` |
| macOS | `Launch.app` | `Launch.command` |

- 주소: **http://127.0.0.1:7788**
- 이미 떠 있으면 브라우저만 엽니다.

---

## 처음 써 보기

1. 오른쪽 위 **`+ 워커`**
2. **역할 이름**(예: `클라 구현`, `리뷰어`)과 **작업 폴더**를 정하고 **띄우기**
   - 📁 버튼으로 폴더 선택 창을 열 수 있고, 최근 쓴 폴더는 목록에서 고를 수 있습니다
   - **권한 모드**: 승인 필요 / 편집 자동 허용 / 계획 먼저 / 전부 허용
   - **추가 인자**: `--model sonnet` 처럼 `claude` 에 그대로 넘길 옵션
   - **역할 저장**을 켜 두면 워커를 지운 뒤에도 빈 자리(소켓)로 남아 버튼 한 번에 다시 띄웁니다
3. 처음 여는 폴더면 터미널에서 신뢰 여부를 한 번 선택합니다
4. 오른쪽 **업무 지시** 칸에 할 일을 적고 **Alt+Enter**(macOS **⌘+Enter**)

> 카드의 역할 이름은 **더블클릭**해서 바꿀 수 있고, 카드를 **끌어서** 순서를 바꿀 수 있습니다.

## 화면 둘러보기

### 워커 카드와 상태

| 상태 | 뜻 |
|---|---|
| 부팅 중 | Claude 가 켜지는 중 |
| 입력 대기 | 일을 기다리는 중 |
| 작업 중 | 일하는 중 — 카드에 지금 쓰는 도구가 보입니다 |
| **결정 필요** | 승인 요청 대기 — 주황색으로 튀어요. 결정함에서 답하세요 |
| 백그라운드 대기 | 턴은 끝났지만 서브에이전트·감시(Monitor)·백그라운드 명령이 아직 도는 중 |
| **완료** | 일을 마침 — 눌러 볼 때까지 초록 빛으로 깜빡입니다 |
| 확인됨 | 완료 후 카드를 눌러 확인함 |
| 중단됨 | 사용자가 중단함 (⏸ 중단 또는 Esc) |
| 종료됨 | Claude 프로세스가 끝남 |

- 카드의 `ctx 195k` 같은 배지는 컨텍스트가 커져 비용이 늘어나는 구간이라는 경고입니다
- 화면 위 칩에서 상태별 워커 수를 한눈에 봅니다
- 회로 기판 가운데의 흰 클로드가 매니저이고, 배지 숫자는 지금 작업 중인 워커 수입니다

### 결정함 (승인 요청)

워커가 권한을 요청하면 화면 맨 위에 쌓입니다.

- **허용** / **거부** / **사유와 함께 거부**(입력한 사유가 Claude 에게 전달됨)
- 10분 가까이 답하지 않으면 해당 워커의 터미널 프롬프트로 넘어가 거기서 답할 수 있습니다
- 탭 제목에 대기 중인 결정 수가 `(2) 클로드 키우기` 처럼 표시됩니다

### 워커 상세 (카드를 눌렀을 때)

- **터미널** — 그 워커의 실제 Claude 화면. 아래 가로선을 끌어 높이 조절(더블클릭: 기본 높이), **⛶ 크게** 로 전체 화면
- **업무 지시** — 작업 중이면 대기열에 쌓이고, 대기열 항목은 ✕ 로 뺄 수 있습니다
- **나중에 할 작업** — 자동으로 실행되지 않는 메모. 역할별로 저장되고 ▶ 지시 를 눌러야 투입됩니다
- **타임라인** — 요청 · 도구 사용 · 결정 기록. **요청 줄을 누르면 터미널이 그 요청 위치로 스크롤**됩니다
- **⏸ 중단** — 진행 중인 작업 중단(Esc 전송) · **제거** — 목록에서 지우고 실행 중이면 종료

### 세션 프로파일

상세 화면 아래, 제목을 눌러 접고 펼 수 있습니다(접어도 한 줄 요약은 계속 갱신).

- 누적 토큰 · 추정 비용 · 현재 컨텍스트 · 캐시 적중률
- 턴별 입력(캐시 읽기/쓰기/신규) · 출력 토큰 차트
- 턴별 소요 시간 — 모델 응답 / 도구 실행 / 승인 대기 / 기타
- 도구별 사용 횟수 · 소요 시간, 서브에이전트 목록, 최근 턴 표
- 각 항목의 ⓘ 에 읽는 법과 활용 팁이 있습니다

> 비용은 Claude Code 기록(.jsonl)을 API 단가로 환산한 **추정치**입니다. 구독 요금제라면 실제 청구액과 다릅니다.

### 워커 비교

워커 카드 아래에 붙어 있고, 제목을 눌러 접을 수 있습니다. 행을 누르면 그 워커가 열립니다.

## 입력 · 단축키

| 어디서 | 키 | 동작 |
|---|---|---|
| 업무 지시 · 나중에 할 작업 | **Alt+Enter** / ⌘+Enter | 보내기 · 추가 |
| 〃 | Enter | 줄바꿈 |
| 터미널 | Ctrl+Enter / Shift+Enter | 줄바꿈 (Claude 입력창 안에서) |
| 터미널 | Ctrl+C (선택 영역 있을 때) / Ctrl+V | 복사 / 붙여넣기 |
| 확인 팝업 | Enter / Esc | 확인 / 취소 |

**이미지 첨부** — 업무 지시 · 나중에 할 작업 칸이나 터미널에 이미지를 **끌어다 놓거나 Ctrl+V**. 파일이 저장되고 경로가 들어가며, Claude 가 이미지로 읽습니다.

## 종료와 재시작

오른쪽 위 **⏻** 버튼:

- **↻ 서버 재시작** — 워커는 그대로 두고 대시보드 서버만 다시 켭니다
- **서버만 종료** — 워커(Claude 세션)는 계속 돌고, 다음에 실행하면 그대로 다시 붙습니다
- **서버 + 워커 모두 종료**

워커만 전부 끄기:

```bash
npm run stop-workers
```

`git pull` 등으로 서버 코드가 바뀌면 화면 위에 **"서버 코드가 바뀌었습니다"** 띠가 뜹니다. **↻ 지금 재시작** 을 누르면 워커는 유지한 채 새 코드로 바뀝니다. (화면 쪽 변경은 브라우저 새로고침만으로 충분합니다.)

## 데이터와 개인 정보

- 모든 데이터는 프로젝트의 `data/` 폴더에만 저장되고 git 에 올라가지 않습니다
  - 워커 목록 · 타임라인, 저장된 역할 · 순서 · 색, 나중에 할 작업, 첨부 이미지, 서버 로그(`data/server.log`)
- 첨부 이미지는 7일 뒤 자동 정리됩니다 (나중에 할 작업에 쓰인 것은 유지)
- 대시보드는 `127.0.0.1` 에만 열려 같은 네트워크의 다른 PC 에서도 접속할 수 없습니다
- 워커에는 상태 수신용 훅이 실행 옵션(`--settings`)으로만 붙습니다. 내 `~/.claude/settings.json` 은 건드리지 않습니다

## 문제 해결

| 증상 | 해결 |
|---|---|
| 브라우저가 안 열리거나 접속이 안 됨 | `Launch.bat`(macOS `Launch.command`)로 실행해 콘솔 메시지 확인, `data/server.log` 확인 |
| 새 기능 버튼을 눌렀는데 "서버가 이 기능을 모릅니다" | 화면 위 **↻ 지금 재시작** 또는 ⏻ → ↻ 서버 재시작 |
| 워커가 `부팅 중` 에서 멈춤 | 카드를 눌러 터미널 확인 — 폴더 신뢰 여부나 로그인 안내가 떠 있을 수 있습니다 |
| `claude` 를 못 찾음 | 터미널에서 `claude` 가 실행되는지 확인. macOS 에서 `Launch.app` 으로 열었다면 `npm run setup-mac` 을 다시 실행 |
| 포트 7788 이 이미 쓰이는 중 | 환경 변수 `AM_PORT` 로 다른 포트 지정 (상주 프로세스는 `AM_PTY_PORT`, 기본 7787) |

## 개발자용: 구조

```
Launch.*          실행기 (app/launch.mjs 호출 — 서버를 창 없이 띄우고 브라우저 열기)
app/server.js     대시보드 서버 · 훅 수신 · 상태 방송(WebSocket)
app/ptyhost.js    Claude 프로세스를 붙잡는 상주 프로세스 — 서버를 재시작해도 워커 유지
app/hook.mjs      워커의 Claude Code 훅 → 서버 전달
app/profile.js    트랜스크립트(.jsonl) → 토큰 · 비용 · 시간 집계 (pricing.js 단가)
app/public/       화면 (index.html · app.js · style.css)
data/             로컬 데이터 (git 제외)
```

서버만 직접 실행: `npm start`
