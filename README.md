# 클로드 키우기 (agent-manager)

내 PC 의 **여러 Claude Code 세션(워커)을 브라우저 한 화면에서 관리**하는 로컬 대시보드입니다.
일을 나눠 주고, 진행을 지켜보고, 승인 요청에 답합니다. 워커는 평소 쓰는 `claude` CLI 그대로라 슬래시 명령·스킬·MCP·설정이 같습니다.

- `127.0.0.1` 에서만 열리는 **내 PC 전용** 도구입니다 (외부 통신·원격 접속 없음)
- 대시보드를 재시작해도 **워커는 끊기지 않고** 다시 붙습니다

## 준비물

- **Node.js 20 이상**
- **Claude Code CLI** — 터미널에서 `claude` 가 실행되고 로그인되어 있어야 합니다
- Windows 10/11 또는 macOS

## 설치

**Claude 에서 셋업하는 것을 권장합니다.**

```bash
git clone https://github.com/stzjinseong/agent-manager.git
```

클론한 폴더에서 `claude` 를 열고 `/setup --mac` (Windows 는 `/setup --windows`) — 확인부터 설치까지 대신 해 줍니다.
macOS 에서 `Launch.app` 을 처음 열 때 보안 경고가 뜨면 Finder 에서 **우클릭 → 열기**.

## 실행

| | 보통 | 문제 볼 때 (콘솔 창) |
|---|---|---|
| Windows | `Launch.vbs` (또는 PowerShell 에서 `agent-manager`) | `Launch.bat` |
| macOS | `Launch.app` (또는 터미널에서 `agent-manager`) | `Launch.command` |

더블클릭하면 브라우저가 **http://127.0.0.1:7788** 로 열립니다. 이미 떠 있으면 브라우저만 엽니다.

## 처음 써 보기

1. 오른쪽 위 **`+ 워커`** → **역할 이름**과 **작업 폴더**를 정하고 **띄우기**
   - 권한 모드, `claude` 추가 인자(예: `--model sonnet`)를 고를 수 있습니다
   - **역할 저장**을 켜 두면 워커가 끝나도 **대기실** 카드로 남아 **▶ 투입** 한 번에 다시 띄웁니다
2. 처음 여는 폴더면 터미널에서 신뢰 여부를 한 번 선택
3. 카드를 눌러 오른쪽 **업무 지시** 칸에 할 일을 적고 **Alt+Enter** (macOS **⌘+Enter**)

카드 이름은 **더블클릭**으로 바꾸고, 카드를 **끌어서** 순서를 바꿉니다.

## 화면

**워커 카드** — 상태(작업 중 · **결정 필요** · 완료 · 백그라운드 대기 · 중단됨 · 종료됨 등)와 지금 하는 일, 할 일 진행, 경과 시간, 비용.
완료된 카드는 눌러 볼 때까지 흰 빛으로 깜빡이고, `ctx 195k` 배지는 컨텍스트가 커져 비용이 늘어나는 구간이라는 경고입니다.

**결정함** — 승인 요청이 화면 맨 위에 모입니다. **허용 / 거부 / 사유와 함께 거부**. 대기 중인 수는 탭 제목에도 `(2)` 처럼 표시됩니다.

**워커 상세** (카드를 눌렀을 때)
- **터미널** — 그 워커의 실제 Claude 화면. 직접 입력해도 됩니다. 아래 가로선으로 높이 조절, **⛶ 크게** 로 전체 화면(넓은 화면이면 오른쪽에 지시·메모·타임라인이 함께)
- **업무 지시** — 작업 중이면 **대기열**에 쌓였다가 지금 일이 끝나면 이어서 투입. ✕ 로 뺄 수 있습니다
- **나중에 할 작업** — 자동 실행되지 않는 메모. **▶** 로 투입, **수정** 으로 고치기, **다른 워커 카드로 끌어다 놓아** 옮기기
- **타임라인** — 요청·도구 사용·결정 기록(아래가 최신). 요청 줄을 누르면 터미널이 **그 위치로 스크롤**됩니다(오래돼 터미널 기록에서 밀려난 요청은 흐리게 표시)
- **캡처** — Claude 가 본 이미지(스크린샷·이미지 파일)와 내가 첨부한 이미지가 타임라인에 썸네일로 보입니다. 누르면 크게, ←/→ 로 넘겨 보기
- **⏸ 중단** (Esc 전송) · **제거** (목록에서 지우고 실행 중이면 종료)

**세션 프로파일** — 토큰 · 추정 비용 · 컨텍스트 · 캐시 적중률 · 응답 시간 · 오류 · 도구 · 서브에이전트, 턴별 차트와 최근 턴 표.
각 항목의 ⓘ 에 읽는 법이 있습니다. 비용은 API 단가로 환산한 **추정치**라 구독 요금제의 실제 청구액과 다릅니다.

**워커 비교** — 카드 아래 접이식 표. 워커들의 토큰 · 비용 · 캐시 · 컨텍스트를 나란히 봅니다.

**매니저 클로드** — 가운데의 흰 클로드. 워커가 일을 마칠 때마다 경험치를 얻어 모습이 조금씩 바뀝니다(머리 위 바에 마우스를 올리면 진행도).

## 단축키 · 입력

| 어디서 | 키 | 동작 |
|---|---|---|
| 업무 지시 · 나중에 할 작업 | **Alt+Enter** / ⌘+Enter | 보내기 · 추가 · 수정 저장 |
| 〃 | Enter | 줄바꿈 |
| 터미널 | Ctrl+Enter / Shift+Enter | Claude 입력창 안 줄바꿈 |
| 터미널 | Ctrl+C (선택 시) / Ctrl+V | 복사 / 붙여넣기 |
| 팝업 · 크게 보기 | Esc | 닫기 |

**이미지 첨부** — 업무 지시 · 나중에 할 작업 칸이나 터미널에 이미지를 **끌어다 놓거나 Ctrl+V**.

## 종료 · 재시작

오른쪽 위 **⏻** — **↻ 서버 재시작**(워커 유지) / **서버만 종료**(워커는 계속 돌고 다음 실행 때 다시 붙음) / **서버 + 워커 모두 종료**.
워커만 전부 끄려면 `npm run stop-workers`.

업데이트(`git pull`) 뒤 화면 위에 **"서버 코드가 바뀌었습니다"** 가 뜨면 **↻ 지금 재시작** 을 누르세요. 화면만 바뀐 경우는 새로고침이면 됩니다.

## 데이터

모든 데이터는 프로젝트의 `data/` 폴더에만 저장되고 git 에 올라가지 않습니다.
첨부 이미지는 7일 뒤 자동 정리되고(나중에 할 작업에 쓰인 것은 유지), Claude 가 본 캡처는 워커당 최근 50장만 둡니다.
내 `~/.claude/settings.json` 은 건드리지 않습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 브라우저가 안 열림 | `Launch.bat` / `Launch.command` 로 실행해 콘솔 메시지 확인, `data/server.log` 확인 |
| "서버가 이 기능을 모릅니다" | ⏻ → **↻ 서버 재시작** |
| 워커가 `부팅 중` 에서 멈춤 | 카드를 눌러 터미널 확인 — 폴더 신뢰·로그인 안내가 떠 있을 수 있습니다 |
| `claude` 를 못 찾음 | 터미널에서 `claude` 가 되는지 확인. macOS 는 `npm run setup-mac` 다시 실행 |
| 포트 7788 이 이미 사용 중 | 환경 변수 `AM_PORT` 로 다른 포트 지정 |
